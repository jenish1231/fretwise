# octave shape 1
- only applies to 6 & 5 string
- a note 2 frets up and 2 string down
- same note an octave higher

# octave shape 2
- only applies to 4 & 3 string
- a note 3 frets up and 2 string down
- same note an octave higher

# octave shape 3
- only applies to 5 & 4 string
- a note 2 frets down and 3 string down.
- same note an octave higher

# octave shape 4
- any note on the high e string is the same as the note on the low E string
for the same fret - 2 octave higher.
